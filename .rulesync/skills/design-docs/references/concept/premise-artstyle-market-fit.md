# 题材、画风与市场适配

用于概念阶段审视题材、画风、视觉关键词、市场认知、制作可行性和扩展空间。目标是确认题材与画风能支撑核心体验和目标玩家预期，而不是只作为包装或宣传词。

市场饱和度、竞品密度、资产成本、团队产能和技术可行性只能引用已确认约束或 `EVID-*`；缺失时交 `design-evidence` 调查，本模块不凭经验补事实。

## 核心原则

- 题材不是皮肤；题材要能解释玩家反复做的核心动作。
- 画风不是“好不好看”；画风要传达目标情绪、商店第一印象和制作边界。
- 主题、题材、画风三者要分开写：主题是玩家感受到什么，题材是语义载体，画风是视觉表达方式。
- 市场认知不是追热点；要判断目标玩家是否熟悉、是否接受、是否已过度饱和。
- 制作可行性是概念约束，不是美术开工后才处理的执行问题。

## 题材审视

| 维度 | 检查问题 | 风险 |
|------|----------|------|
| 语义支撑 | 题材能否自然解释核心循环动词 | 核心动作像硬凑，玩家无法代入 |
| 行为合理性 | 玩家在题材内的行动是否说得通 | 玩法与世界观互相拆台 |
| 情感共鸣 | 目标玩家是否天然理解或喜欢该题材 | 需要额外教育市场 |
| 内容承载 | 题材能否持续产出角色、道具、场景、事件 | 中后期内容枯竭 |
| 扩展空间 | DLC、续作或长线内容是否能自然延展 | 后续内容只能换皮 |
| 文化风险 | 是否有文化敏感、版权、政治或平台风险 | 发布和传播风险 |

自检：
- 把核心循环动词放进题材里读一遍，是否自然。
- 换掉题材后核心体验是否仍完全不变；如果不变，题材可能只是装饰。
- 同题材成功案例服务的是不是同一目标玩家和同一核心体验。

## 题材市场认知（引用 `EVID-*`）

| 维度 | 判断 |
|------|------|
| 熟悉度 | 高 / 中 / 低：目标玩家是否需要先学习题材 |
| 饱和度 | 过热 / 适中 / 蓝海：同题材竞品密度如何 |
| 视觉辨识度 | 高 / 中 / 低：一张截图或商店图能否识别题材 |
| 误解风险 | 玩家是否会带入错误的品类预期 |

## 画风审视

| 维度 | 检查问题 | 风险 |
|------|----------|------|
| 风格名称 | 能否用一个稳定名称描述，而不是只说“好看” | 团队脑中画面不一致 |
| 视觉关键词 | 是否有 3 到 5 个可执行关键词 | 美术、UI、宣传图各做各的 |
| 核心张力 | 是否有可记忆的视觉矛盾或独特点 | 缺少商店第一眼差异 |
| 题材匹配 | 画风能否传达题材核心气质 | 题材和视觉互相削弱 |
| 体验支撑 | 画风是否强化主驱动力和核心情绪承诺 | 画面情绪与玩法目标相反 |
| 情绪基调 | 亮度、色彩、材质、比例、镜头是否输出同一感受 | 局部表现割裂 |
| 辨识度 | 缩略图、截图、短视频首帧是否有识别点 | 市场传播弱 |

## 制作可行性（引用 `EVID-*` 或已确认约束）

| 维度 | 检查问题 |
|------|----------|
| 团队能力 | 当前团队是否能稳定产出该风格 |
| 制作效率 | 单个角色、场景、UI、特效的产出成本是否可接受 |
| 资产复用 | 模块化、换色、材质复用、动画复用空间有多大 |
| 内容扩展 | 新关卡、新角色、新道具是否能保持风格一致 |
| 技术约束 | Unity 渲染、性能、平台、包体是否支持该表现方向 |
| 商业预期 | 画风是否支撑定价、买断感、F2P 长线或目标用户审美 |

## 预设观察信号

概念案只声明需要验证的理解、视觉一致性和制作信号；外部访谈、市场调查、成本取证和归因交 `design-evidence`。

- 非项目成员看到一句话概念和关键图后，能否说出题材、目标体验和玩家身份。
- 目标玩家看到截图、商店缩略图或 moodboard 后，能否理解情绪基调和品类预期。
- 美术、UI、关卡和宣传图能否用同一组视觉关键词解释自己的取舍。
- 核心资产成本、首发内容量和后续扩展能力是否已有可定位证据。
