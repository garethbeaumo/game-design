# 策略互动与收益结构

用于战斗、PVP、PVE 对抗、阵营、合作任务、外交、交易、技能克制、构筑克制、公共资源竞争或多人协作。目标是把“玩家之间或玩家与系统之间如何互相影响”写成可比较的收益结构，而不是只写强弱、克制或策略空间。

## 使用原则

- 先识别行动者：玩家、敌人、队友、阵营、系统事件或市场都可以是行动者。
- 只有当一个行动会改变另一方选择或收益时，才需要收益矩阵；单人线性流程不要强行套博弈术语。
- 先写玩家可见决策，再写系统结算；玩家看不见的收益结构很难形成策略。
- 不追求严格数学证明，用收益矩阵发现占优策略、无效选项、搭便车、合谋、僵局和不公平感。

## 互动类型

| 类型 | 适用场景 | 检查重点 | 常见风险 |
|------|----------|----------|----------|
| 零和对抗 | 竞技、排位、短局 PVP | 胜负收益、信息公平、先后手、匹配 | 滚雪球、先手必胜、败方无反制 |
| 非零和竞争 | 竞速、拍卖、公共市场、排行榜 | 多人都能获益或受损的条件 | 合谋、压价、垄断、低风险套利 |
| 合作 | 副本、团队任务、公会目标 | 分工收益、贡献识别、失败连带 | 搭便车、辅助位无成就感、责任不清 |
| 合作中对抗 | 阵营、外交、临时联盟 | 背叛收益、信誉、重复博弈 | 囚徒困境、背刺最优、沟通成本过高 |
| 公共资源竞争 | 地图资源、世界事件、公共进度 | 个人收益与整体损耗 | 公地悲剧、最后一击抢功、贡献不可见 |
| 自愿者困境 | 需要有人牺牲或承担任务 | 谁承担成本、如何补偿 | 所有人等待别人做、牺牲者体验差 |

## 收益矩阵字段

| 字段 | 说明 |
|------|------|
| actor | 行动者，如玩家 A、敌人、队友、阵营、市场 |
| action | 行动者可选行动 |
| other_action | 另一方可能行动或系统状态 |
| private_payoff | 对该行动者的个人收益 / 损失 |
| shared_payoff | 对队伍、阵营、市场或公共资源的收益 / 损失 |
| information | 玩家在决策前能看见什么信息 |
| counterplay | 对手或系统是否有可理解的反制 |
| dominant_risk | 是否存在任何情况下都更优的占优策略 |
| exploit_risk | 是否存在合谋、搭便车、刷分、低风险套利或拖延 |

## 克制与 RPS 结构

| 检查项 | 要求 |
|--------|------|
| 克制关系 | 每个强选项至少有一个可读、可执行的反制路径 |
| 成本 | 强选项需要成本、窗口、冷却、资源或暴露弱点 |
| 读招 | 被克制方必须能提前看到信号，而不是结算后才知道 |
| 软硬程度 | 强 PVP 优先软克制；硬克制必须有换路、换装、禁用或重开边界 |
| 例外 | 允许少量打破循环的特殊牌，但要有限制和反制 |
| 教学 | 新手先理解三角关系，再接触例外、混合克制或隐藏信息 |

## 占优策略与均衡诊断

- 如果一个选项在大多数场景下都更安全、更高收益、更低成本，它会压扁策略空间。
- 如果玩家理性选择会导致所有人体验变差，如全员防守、全员囤积、无人承担公共任务，需要改收益而不是指责玩家。
- 如果存在玩家都能更好的帕累托改进，但玩家无法协调，需要增加沟通、信任、承诺、匹配或系统自动分配。
- 如果均衡结果是僵局、拖时间、互相不行动或只刷低风险收益，需要提高主动行动收益或增加不行动成本。
- 如果最优策略依赖隐藏公式或无法读懂的信息，玩家会把失败归因为不公平。

## 公平与信息透明

- 竞技、公平排行榜和强 PVP 默认要求关键信息透明：规则、胜负条件、伤害来源、收益结算、克制关系和失败原因。
- 隐藏信息可以存在，但要可学习、可推断、可复盘；不能让玩家只感觉被系统偷袭。
- 随机性需要说明可控部分、不可控部分和失败后的复盘线索。
- 队伍合作中，贡献反馈要区分输出、控制、治疗、承伤、侦查、搬运、牺牲和组织行为，避免只奖励最后一击或最高伤害。

## 预设观察信号

功能规则可以做静态表格推演并声明观察问题；真实玩家测试、数据分析和归因必须交 `design-evidence:playtest`。

- 静态推演：3 到 5 个典型局面中是否总是同一个行动最优。
- 极端画像：保守、冒险、合谋、搭便车和高熟练策略可能如何利用规则。
- 反制信号：强选项是否可读、可反应，并给对手合理回报。
- 复盘信号：失败玩家能否说明输在哪里、对方做对什么、下次可换什么策略。
- 公共资源信号：个人最优是否会长期破坏团队、阵营、市场或世界状态。
