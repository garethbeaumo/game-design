# game-design

中文游戏策划 Skills：证据、推论、正式落档、工作流治理与定案前拷问。

## Skills

| Skill | 职责 |
|-------|------|
| `design-workflow` | 路线、里程碑、产物治理与入口路由 |
| `design-evidence` | 竞品 / 试玩 / 实现事实 |
| `design-inference` | 候选、取舍、`DEC-*`、Prototype |
| `design-docs` | 已确认概念 / 系统地图 / 功能规则 |
| `grill-me` | 高影响阻塞分支确认 |

## 目录

源文件在 `.rulesync/skills/`。可用 [rulesync](https://github.com/dyoshikawa/rulesync) 同步到 Cursor / Claude / Codex 等目标。

## 校验

```powershell
pwsh -NoProfile -File .rulesync/skills/design-workflow/scripts/validate-planning-skills.ps1
```
