# 当前设计权威

## 概念基线

- 玩家在信息不完整的战术行动中，通过观察、沟通和协作完成任务。
- 核心循环：接收任务 → 侦察 → 交战或规避 → 完成目标 → 撤离。
<!-- KEEP: concept-baseline-v1 -->

## 系统登记

| 系统 | 当前性 | 职责 | 依赖 |
|---|---|---|---|
| 任务系统 | current | 生成目标、约束与结算条件 | 战斗系统、奖励系统 |
| 战斗系统 | current | 处理交战、伤害与失败恢复 | 任务系统 |
| 奖励系统 | current | 根据任务结算发放奖励 | 任务系统 |

## 功能规则

### 任务生成

- 每局生成一个主目标和至多两个可选目标。
- 无可达路径时重新选择目标区域。

### 战斗受击

- 受击后立即显示方向反馈。
- 伤害结算失败时保持上一个已确认生命值。

## 未受影响基线

- 奖励结算只读取任务结果，不读取环境表现。
