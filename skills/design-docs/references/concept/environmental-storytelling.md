# 环境叙事与世界线索

用于设计世界状态、阵营冲突、角色空间、关卡线索、环境 Sign、氛围信息和不打断流程的叙事表达。目标是让玩家通过观察和行动理解世界，而不是把主线目标、核心规则或复杂情节藏进低可见度装饰。

## 叙事信息分级

先判断信息的重要性，再选择环境线索强度。

| 信息级别 | 例子 | 表达要求 |
|----------|------|----------|
| 关键目标 | 要去哪里、做什么、为什么现在要做 | 不能只靠环境叙事，必须有明确 Sign / UI / 任务反馈 |
| 核心规则 | 可互动对象、危险规则、失败原因 | 必须可观察、可验证，有即时 Feedback |
| 世界状态 | 谁掌权、哪里危险、资源短缺、阵营变化 | 可用环境线索、NPC 短句、广播、标识补充 |
| 角色信息 | 习惯、价值观、关系、过去行动 | 可用房间陈设、道具磨损、私人痕迹表达 |
| 可选背景 | 历史、传闻、隐藏事件、彩蛋 | 可藏得更深，但不影响主流程理解 |

## 线索载体

| 载体 | 可传达内容 | 风险 |
|------|------------|------|
| 空间布局 | 权力关系、阶级隔离、危险路线、行动限制 | 过度抽象，玩家无法复述 |
| 道具和陈设 | 角色习惯、资源状况、近期事件 | 堆物件但没有叙事指向 |
| 破损、痕迹、遗留物 | 冲突结果、危险来源、过去行为 | 只做气氛，不提供可理解信息 |
| 涂鸦、标识、海报 | 阵营观点、禁令、宣传、反抗 | 变成说明牌或文字墙 |
| 广播、环境音、短对白 | 当前局势、背景压力、风险提示 | 打断操作或反复播放烦人 |
| 光线、地标、路径线 | 安全 / 危险、目标方向、探索优先级 | 和真实可走路径冲突 |
| 可互动环境物 | 规则教学、谜题提示、世界逻辑 | 玩家误以为所有相似物都可互动 |

## 角色空间

角色空间应能让玩家推断角色，而不是只展示美术资产。

| 检查项 | 问题 |
|--------|------|
| 所属关系 | 玩家能否知道这里是谁的空间 |
| 行为痕迹 | 空间是否显示角色最近做过什么 |
| 价值观 | 物品、摆放、磨损是否表达角色偏好或矛盾 |
| 变化 | 剧情或系统变化后，空间是否有可观察变化 |
| 互动意义 | 玩家查看后是否更理解后续选择、风险或关系 |

## 自然放置

- 线索应出现在玩家自然经过、战斗间隙、探索节点或决策节点。
- 不要把主线必需信息放在低对比角落、长文本、可错过收集品或一次性广播里。
- 环境线索要服务当前任务、世界理解或主题表达；不能只是“这里需要一些装饰”。
- 同一种线索语言要保持一致：同样的警戒色、封锁标识、可破坏痕迹应表达同类含义。
- 线索密度要随节奏变化：高压段少解释，低压段允许观察和拼接信息。

## 预设观察信号

概念案只定义理解目标与风险信号；实际试玩、复述访谈、观察和归因交 `design-evidence:playtest`。

- 玩家能否复述这里发生过什么、谁在控制、哪里危险以及下一步为什么合理。
- 玩家是否被错误线索吸引到无关位置，或把氛围物件误认为可互动对象。
- 玩家是否必须读长文本才能理解主目标；若是，环境叙事承担了不该承担的职责。
- 玩家是否完全忽略线索；后续归因应区分位置、对比、节奏、奖励和反馈，而不是直接增加文字。

## 输出片段

```markdown
## 环境叙事计划
| 信息 | 级别 | 线索载体 | 放置位置 | 玩家应推断什么 | 验证方式 |
|------|------|----------|----------|----------------|----------|
| | 关键目标 / 核心规则 / 世界状态 / 角色信息 / 可选背景 | | | | |

## 角色空间
| 角色 / 阵营 | 空间元素 | 表达信息 | 后续影响 | 风险 |
|-------------|----------|----------|----------|------|
| | | | | |

## 线索风险
| 风险 | 影响 | 修正 |
|------|------|------|
| 关键目标藏太深 | 主流程断裂 | 改用明确 Sign / UI / 任务反馈 |
| 装饰误导互动 | 玩家浪费时间 | 统一可互动视觉语言 |
| 线索太像说明牌 | 沉浸感下降 | 改为空间、痕迹、行为结果表达 |
```
