# 玩家动机与情绪承诺

用于定义目标玩家为什么会被游戏吸引、反复回来、愿意投入，以及游戏承诺的核心情绪如何被机制和反馈兑现。适用于概念案、核心体验、系统驱动力、社交 / 收集 / 探索 / 挑战玩法、情绪曲线和目标玩家验证。

## 使用原则

- 动机不是人口标签；要写玩家想获得什么体验、证明什么、展示什么或逃离什么。
- 情绪承诺要能被机制兑现；不能只靠文案、美术或宣传语。
- 区分“驱动探索的新鲜感”和“巩固投入的成就 / 归属 / 收藏 / 表达”，只靠一边容易快速疲劳。
- 不把心理学分类当成硬标签；它们只是帮助检查遗漏和冲突。

## 动机类型

| 动机 | 玩家追求 | 适合机制 | 常见风险 |
|------|----------|----------|----------|
| 好奇 / 发现 | 新内容、新规律、新秘密 | 探索、解锁、随机事件、环境线索 | 发现耗尽后无事可做 |
| 精通 / 挑战 | 变强、变熟、攻克难关 | 技能挑战、Boss、谜题、排名 | 门槛太高或失败不可归因 |
| 成就 / 积累 | 完成、收集、成长可见 | 成就、图鉴、养成、里程碑 | 只剩清单劳动 |
| 表达 / 身份 | 创造、装扮、构筑、自我展示 | 建造、外观、角色扮演、创作工具 | 被唯一最优解绑架 |
| 社交 / 归属 | 一起玩、被需要、被认可 | 公会、组队、协作、分享、互赠 | 个人贡献不可见或社交压力过重 |
| 竞争 / 地位 | 赢、排名、支配、被看见 | PVP、排行榜、赛季、对抗 | 失败方无望、强者滚雪球 |
| 放松 / 陪伴 | 安全、低压、规律、陪伴感 | 轻度循环、装饰、照料、日常 | 目标过弱导致无意义感 |
| 叙事 / 共情 | 情感旅程、角色连接、价值判断 | 剧情选择、环境叙事、角色关系 | 机制行为与叙事情绪冲突 |

## 四类乐趣检查

| 乐趣 | 设计问题 | 证据 |
|------|----------|------|
| Easy Fun / 好奇 | 玩家是否被未知、变化或可发现内容吸引 | 主动探索、停留观察、复述发现 |
| Hard Fun / 克服 | 玩家是否愿意承受困难并获得成就 | 失败后重试、说明改进策略 |
| Serious Fun / 意义与积累 | 玩家是否觉得投入有价值、有进度、有收藏或表达意义 | 回看进度、规划目标、维护收藏 |
| People Fun / 与人有关 | 玩家是否因协作、竞争、陪伴、展示或归属而留下 | 邀请、组队、分享、讨论、互助 |

健康的核心体验通常至少有一个探索驱动和一个巩固驱动。若只有探索，内容消耗完会掉线；若只有巩固，玩家可能知道“有收益”但没有打开下一次的动机。

## 情绪承诺

| 字段 | 要求 |
|------|------|
| 核心情绪 | 玩家每次完成短循环后应留下什么感受 |
| 情绪来源 | 该情绪来自行动、反馈、风险、叙事、社交还是成长 |
| 反向情绪 | 明确不希望频繁产生的感受，如羞辱、焦虑、空虚、被迫营业 |
| 高光时刻 | 玩家会截图、复述、分享或想再来一次的瞬间 |
| 低谷处理 | 失败、等待、重复、落后、断线、错过时如何保持可恢复 |
| 证据 | 目标玩家的表情、话语、行为、复述、返回或分享 |

## 动机冲突

- 休闲放松与强竞争排名冲突时，默认先保护主要目标玩家的安全感。
- 表达与唯一最优冲突时，要提供外观 / 玩法分离、软约束、重置或展示场景。
- 社交归属与强责任压力冲突时，要明确可选参与、异步贡献和低惩罚缺席。
- 探索与效率刷取冲突时，要让首见、路线变化、环境线索或发现奖励有足够价值。
- 挑战与公平感冲突时，要保证失败可归因、可复盘、可改进。

## 预设观察信号

概念案只声明要验证的动机和情绪信号；实际招募、访谈、行为观察、样本限制和归因交 `design-evidence:playtest`。

- 玩家能否复述“为什么想继续玩”，而不只是回答喜不喜欢。
- 探索、重试、收藏、展示、组队、分享、优化和放松停留等主动行为。
- 笑、懊恼、惊讶、得意、沉默、退出、截图和转述等强情绪点。
- 预期主动力与真实行为是否一致：玩家是否在做项目希望他们享受的事。
- 内部样本只能作为带偏差的输入，不能直接升级为目标玩家动机证据。
