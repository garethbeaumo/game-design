# 玩家信任与魔法圈边界

用于设计会把玩家带出游戏内体验的机制：现实时间、登录 / 签到、体力、等待、社交义务、排行榜、赛季、付费、广告、概率奖励、永久损失或缺席惩罚。目标是确认这些外部压力是否服务核心体验，而不是用压力、愧疚或不透明规则替代乐趣。

## 判断原则

- 魔法圈不是不能被打破，而是要有清楚契约：玩家知道自己为何被要求等待、回来、比较、付费或承担损失。
- 元游戏、长线成长和商业化只能放大核心循环；如果最优行为变成跳过核心玩法、只刷菜单、只等时间或只付费，说明边界失控。
- 玩家信任优先于短期参与数据。登录率、停留时长或付费率上升，不能自动证明设计健康。
- 对休闲、低压力、未成年或买断目标玩家，现实压力和不透明随机的风险要按更严格标准处理。

## 外部压力类型

| 类型 | 可接受用途 | 主要风险 | 保护方式 |
|------|------------|----------|----------|
| 现实时间 / 体力 / 冷却 | 控制节奏、制造计划、保护内容消耗 | 玩家只等时间、不玩核心循环 | 可见恢复、上限、替代玩法、离线收益边界 |
| 登录 / 签到 / 连续奖励 | 提醒回访、形成短期目标 | 错过即亏、把游戏变成负担 | 补领、宽限、低损失断连、周期上限 |
| 排行 / 赛季 / 段位 | 提供挑战、身份和目标 | 焦虑、滚雪球、失败方无望 | 分层匹配、软重置、非竞争路线、保护期 |
| 社交义务 / 公会 / 赠礼 | 归属、协作、被需要 | 被群体压力强迫上线或付费 | 可选贡献、匿名贡献、非付费贡献、退出无重罚 |
| 付费 / 广告 / 订阅 | 明确价值交换、支持长期内容 | P2W、误导、付费断点、沉浸破坏 | 真实成本、免费路径、上限、概率和折扣透明 |
| 永久损失 / 衰退 / 缺席惩罚 | 赌注、风险回报、硬核承诺 | 长期投入被否定、直接流失 | 明示选择、预览、保险、恢复窗口、可选模式 |
| 变量奖励 / 抽取 / 掉落 | 惊喜、复玩、探索未知 | 黑箱、成瘾式刷取、沉没成本 | 概率、保底、期望值、上限、疲劳控制 |

## 失控信号

- 玩家复盘时说的是“怕亏”“不得不上线”“不付费就没法玩”，而不是核心动作本身。
- 玩家最优策略绕开核心循环，转为等恢复、刷低风险内容、囤资源、反复进菜单或追逐红点。
- UI、文案、倒计时、稀有度或排行榜放大损失厌恶，但没有给出真实成本和退出路径。
- 数据只证明参与增加，却没有证明目标玩家更理解、更享受或更信任系统。
- 付费、社交、排名或缺席惩罚让非目标玩家被迫成为主要收入或活跃来源。

## 预设观察信号

这里只定义信任边界的验证问题；实际分层测试、访谈、行为证据与归因交 `design-evidence:playtest`。

- 复述信号：目标玩家能否说清为什么要等待、回来、竞争、付费或承担损失。
- 行为信号：玩家是否仍主动进入核心循环，而不是只执行外部压力驱动的最低成本动作。
- 分层信号：新手、轻度、重度、付费、非付费和回流玩家承受的压力是否不同。
- 回退问题：关闭登录、排行、付费捷径或缺席惩罚后，核心循环是否仍成立。
