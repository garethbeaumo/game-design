# 主题、机制与表现协同

用于创建游戏主题、题材、叙事基调、机制组合、环境叙事和表现方向。目标是让主题成为可执行的设计约束，而不是停留在美术风格或宣传词。需要细化世界状态、阵营冲突、角色空间、关卡线索或环境叙事验证时，读取 `environmental-storytelling.md`。

## 主题不是题材

主题是游戏希望玩家感受到或理解的中心信息；题材是包装和设定。相同题材可以表达不同主题，相同主题也可以落在不同题材中。

| 维度 | 要求 |
|------|------|
| 主题 | 能用一句话说明玩家最终感受到什么 |
| 玩家动作 | 核心动作会反复强化该主题 |
| 机制反馈 | 成功、失败、奖励和惩罚都支持主题 |
| 表现 | 美术、音频、动画、镜头和 UI 不输出反向情绪 |
| 叙事线索 | 环境、道具、NPC 和空间布局自然补充世界信息 |

常见错误：
- 只有题材词，没有主题判断：例如“赛博朋克”“荒野”“机甲”。
- 机制反主题：文案强调脆弱求生，但机制长期让玩家无风险碾压。
- 表现贴皮：美术和音效很强，但不帮助玩家理解规则、风险或世界状态。
- 环境叙事过载：把主线关键信息藏进低可见度线索，导致玩家无法理解目标。

## 协同检查

先从简单独立机制出发，再判断组合是否产生更深的选择，而不是只堆叠复杂度。

| 检查项 | 问题 |
|--------|------|
| 组合自然性 | 玩家是否能从已有规则推断组合方式 |
| 可读性 | 第一次成功或失败时是否有清楚 Sign / Feedback |
| 深度 | 组合是否带来新策略，而不是固定最优解 |
| 边界 | 是否列出滥用、漏洞、过度强势和无效组合 |
| 主题支撑 | 组合后的行为是否更强化设计支柱和体验基调 |

## 环境叙事

环境叙事适合补充世界状态、角色关系、阵营冲突和氛围，不适合替代主要目标说明或复杂规则教学。

可使用的线索：
- 空间布局：谁掌权、谁被排斥、哪些路线危险。
- 道具和陈设：角色习惯、资源短缺、历史事件。
- 涂鸦、标识、广播、环境音：阵营观点、世界变化、风险提示。
- NPC 短对白：提供背景，但不打断玩家操作。

检查标准：
- 线索放置自然，不像说明牌。
- 玩家不需要停下游戏流程也能捕捉关键信息。
- 关键目标和核心规则仍由明确 Sign / Feedback 支撑。
- 线索能被验证：试玩后玩家能复述预期世界信息。
- 需要线索分级、载体选择、角色空间和误导风险检查时，读取 `environmental-storytelling.md`。
