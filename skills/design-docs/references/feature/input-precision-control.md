# 输入精度与操作目标规格

用于瞄准、QTE、命中框、互动点、拖拽、投掷、蓄力、闪避、格挡、节奏点击、手柄焦点或任何依赖目标大小、距离、移动速度、输入窗口和容错的玩法交互。目标是判断失败来自玩家技能挑战，还是目标规格、输入方式、镜头、反馈或容错设计有问题。

## 设计原则

- 先说明精度要求是否是核心挑战。不是核心挑战时，优先放大目标、缩短距离、增加吸附或扩大输入窗口。
- 同一操作要按目标输入设备分别检查：鼠标、触屏、手柄、键盘和不同屏幕尺寸不能共用同一精度假设。
- 高频操作要降低疲劳：更近、更大、更稳定，或提供默认焦点、吸附、缓冲输入和取消路径。
- 危险或高风险操作可以更慢、更远或多一步确认，但必须让玩家提前看见失败代价。
- 如果专家玩家都打不中或点不中，优先检查目标规格或时间窗口；如果新手普遍失败，优先检查 Sign、练习、容错和反馈。

## 规格字段

| 字段 | 说明 |
|------|------|
| input_device | 鼠标 / 键盘 / 手柄 / 触屏 / 混合 |
| start_point | 光标、角色、准星、手指或焦点的常见起点 |
| target_shape | 命中框、按钮、互动区域或判定区域形状 |
| target_size | 宽、高、半径或屏幕占比 |
| target_distance | 从起点到目标的距离、镜头距离或角色距离 |
| target_motion | 静止、移动速度、方向变化、遮挡或闪烁 |
| timing_window | 可输入窗口、提前输入缓冲、后摇取消或判定帧 |
| tolerance | 吸附、自动瞄准、容错区域、慢动作、预选焦点或辅助模式 |
| feedback | 命中、擦边、失败、冷却、不可达或输入过早 / 过晚反馈 |
| fatigue_risk | 高频重复、长按、精确拖拽、手指遮挡、手柄长列表或连续 QTE |

## 难度与容错

| 目标体验 | 规格倾向 | 风险 |
|----------|----------|------|
| 轻松操作 | 大目标、短距离、长窗口、强反馈 | 缺少挑战感 |
| 技巧挑战 | 中等目标、可学习窗口、稳定规则 | 失败原因不可见会挫败 |
| 高压反应 | 短窗口、移动目标、明确预警 | 输入延迟或镜头遮挡会被认为不公平 |
| 专家上限 | 小目标、远距离、低容错、可复盘 | 新手需要练习区或替代路径 |

## 预设观察信号

本模块只定义后续要观察什么；样本招募、测试执行、录像 / 日志分析、归因和证据强度统一交 `design-evidence:playtest`。

- 按新手、熟练玩家和目标平台用户分层观察命中率、误触率、用时、失败原因和疲劳反馈。
- 预留能区分目标大小、距离、时间窗口、反馈、输入延迟、镜头遮挡和玩家策略错误的日志或录像信号。
- 覆盖静止目标、移动目标、压力情境和长时间重复等场景，但不在功能规则中伪造测试结果。
- 修改目标尺寸、距离或输入窗口后，把专家挑战列为回归问题，实际结论引用新的 `EVID-*`。
