# 按需决策镜头

这些镜头用于暴露候选之间会改变结论的差异，不是完整策划检查表。一次只选一到三个；若某个镜头不会改变选择，就不要展开它，也不要为它创建独立产物。

| 镜头 | 只问会改变选择的问题 |
|------|------------------------|
| 策划对象与因果结构 | 候选改变哪些对象、状态、规则、空间、内容或数值关系；因果链、边界与不变量怎样不同 |
| 目标玩家与体验 | 谁在什么情境下反复做什么；候选兑现或破坏哪项体验承诺 |
| 循环、学习与反馈 | 决策是否有可读输入和结果；下一轮因什么发生变化；失败能否归因和恢复 |
| 互动、收益与公平 | 谁改变谁的选择或收益；信息、反制、贡献是否可见；是否出现占优、搭便车、合谋或僵局 |
| 输入、节奏与可达性 | 目标设备和玩家阶段是否改变精度、疲劳、教学、会话与容错要求 |
| 经济、内容与长期信任 | 最优行为是否仍是核心玩法；来源 / 消耗、外部压力、随机与内容维护是否可持续和透明 |
| 主题与表现协同 | 玩家动作、成功失败反馈和表现是否强化同一含义，而不只是题材贴皮 |
| 制作、迁移与回退 | 候选改变哪些接口、资产、配置、存档、工具和运营流程；失败时能否安全回到基线 |

## 使用方式

1. 先写候选在规则、空间、内容或数值结构上的真实差异，再写玩家可观察后果，不先套理论标签。
2. 玩家体验与制作约束用于检验结构选择，不作为所有策划问题的默认组织轴；只选择会改变结论的镜头。
3. 只在互动确实改变他人收益时使用收益镜头；只在输入精度确实是挑战时展开设备与容错。
4. 把镜头结论写成“差异 / 风险 / 验证信号”，不把通用原则直接升级为硬约束。
5. 真实玩家是否理解、享受或信任候选，仍需 `design-evidence:playtest`；镜头只能形成待验证判断。

```markdown
| 采用镜头 | 候选间关键差异 | 会改变选择的风险 | 最小观察信号 |
|----------|----------------|------------------|--------------|
| | | | |
```
