# 决策记录模板

仅当决定理由需要独立生命周期时读取：会被多个后续产物长期引用、需要正式审批 / 审计，或同一争议会跨轮次复查。高影响、跨系统或用户指定格式本身不要求 `DEC-*`；其余情况写内联决策切片。

```markdown
# DEC-[ID] [决策标题]

| 字段 | 内容 |
|------|------|
| decision_status | `proposed / accepted / superseded`；表示决策审批生命周期，不等同于正式设计的当前性 |
| validation_status | 验证相关时另记 `unverified / supported / rejected` |
| owner | |
| decision_scope | 本记录唯一负责的取舍问题 |
| affected_ids | 受影响的 SYS / RULE / 里程碑或接口 |
| evidence | 来源快照、EVID 或明确假设的指针，不复制全文 |
| last_updated | |
| review_trigger | 版本、指标、实验结果或外部条件变化 |
| supersedes / replaced_by | |

## 当前基线与变化
- 当前做法：
- 为什么现在必须决定：
- 本次改变 / 不改变：

## 约束与候选
| 候选 | 玩家结果 | 关键依据 / 假设 | 跨系统影响 | 可逆性 / 返工 | 最小验证 |
|------|----------|-----------------|------------|---------------|----------|
| 保持基线 / A | | | | | |
| B | | | | | |

## 决定
- 选择与理由：
- 放弃项与反选代价：
- 仍成立的假设：
- 验证信号：
- 失败回退：

## 差量同步
- 需修订的正式设计：
- 需迁移的配置、内容、数据或实现：
- 无需改变的范围：
```

决策记录保存“为什么选择”，不复制证据全文，也不取代确认后的当前设计。规则确认后由 `design-docs` 差量落档；后续条件变化时追加复查结果或以新记录替代，不重写历史理由。
