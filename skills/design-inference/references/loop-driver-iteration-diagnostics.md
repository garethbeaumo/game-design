# 循环驱动力与方案诊断

用于基于已有 `EVID-*` 判断核心循环为什么值得重复、玩家持续学习什么，以及候选修改应验证哪项致命假设。本文件只支持方案推论，不制定版本计划，也不记录实际测试结果。

## 核心判断

- 有趣来自玩家持续学到新规律、新组合、新表达、新目标、新技巧或新社会关系。
- 子系统的价值要看它在循环中承担输入、行动、反馈、目标推进还是长期变化。
- 外围成长、奖励与表现只能放大核心动作，不能救一个本身无趣或不可读的动作。
- 副驱动力只能强化主驱动力；若改变玩家主要动机，应回概念层重新确认方向。

## 动作质量

| 维度 | 决策问题 | 常见风险 |
|------|----------|----------|
| 易理解 | 玩家能否快速说出目标和结果 | 目标不明，只能依赖解释 |
| 易操作 | 输入、响应和镜头是否支撑动作 | 挑战被归因为操作问题 |
| 单独有趣 | 去掉外围奖励后是否仍值得重复 | 只靠奖励硬撑 |
| 直接反馈 | 行动后是否知道发生什么和为什么 | 行动缺少意义感 |
| 灵活与组合 | 是否能适应不同条件并与其他动作组合 | 只在单一场景成立 |
| 可学习 | 重复中是否出现可观察、可验证、可改进的规律 | 只是在执行命令 |

## 驱动力候选

| 驱动力 | 玩家在学习什么 | 常见风险 |
|--------|----------------|----------|
| 发现 | 新内容、新规律、新组合 | 发现耗尽后无事可做 |
| 表达 | 如何创造、装扮、建造或展示 | 约束过重，表达被最优解绑架 |
| 积累 | 如何更快成长、收集或扩张 | 只看数字变大，缺少决策 |
| 博弈 | 如何在约束下取舍和预测 | 过度惩罚或唯一最优 |
| 社交 | 如何协作、竞争或展示身份 | 个人贡献不可见或落后者无望 |
| 技能 | 如何提升操作、反应和执行 | 门槛太高或反馈太弱 |

## 失败模式

| 失败模式 | 证据应显示什么 | 候选处理方向 |
|----------|----------------|----------------|
| 无深度 | 很快掌握后只剩重复劳动 | 增加条件差异、耦合或组合关系 |
| 无反馈 | 不知道行动影响或失败原因 | 强化语义反馈与可观察结果 |
| 无灵活性 | 只在一种场景成立 | 让动作适配多条件与多目标 |
| 无扩展 | 新内容只能换皮 | 预留新动作、条件或目标入口 |
| 无学习点 | 不能形成猜测与改进 | 增加可观察规律和验证机会 |
| 无回退 | 失败后不知道下次改什么 | 明确恢复路径与重新尝试策略 |
